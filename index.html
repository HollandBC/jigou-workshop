从一个铰点开始

打开完整使用说明书与案例教程 · 打开可打印 PDF

机构工坊用于平面机构的几何与运动学设计，支持连杆、齿轮传动、平面凸轮、固定铰点、机架导轨、活动杆导槽，以及整周旋转或区间摆动输入。

  1. 选择示例：点击顶部“机构示例”按钮，在弹出的案例列表中选择。Jansen 行走机构是单腿模型，足端 H 默认记录轨迹；运行或点击“绘制一周轨迹”查看迈步路径。
  2. 搭建结构：选择“铰点”在画布点击；选择“连杆”依次连接两个端点，也可点击空白处生成端点。靠近已有铰点时，绿色圆环表示已吸附。
  3. 设置机架与驱动：用“固定铰点”（G）创建或切换机架支点。选择连杆，点击“设为角度输入”；有固定端时绕该端转动，两端活动时控制杆件的方位角。输入模式可选“整周旋转”或“区间摆动”，后者填写最小 / 最大角度后点击“应用范围”。摆动采用正弦往返，端点平滑换向，频率单位为次/分；不可整周运动的机构不会强行切换旋转。
  4. 绘制移动副：选择“滑块 / 导轨”（S），先点击滑块铰点或空白位置。选择“机架上的导轨”时，再点击一个方向点；选择“活动杆上的导槽”时，再点击安装母杆。属性中“铰接滑块”允许相对转动，“固连”把滑块作为所选杆的一部分，并锁定与导轨的夹角。固定铰点也能作为摇块中心。两种导轨均用虚线，自动覆盖完整周期的滑块行程；“最小显示长度”可手动加长，不限制行程。拖动滑块沿原轨道调整位置，固连时整杆平移；拖动虚线或选中导轨的蓝色手柄平移导轨，活动导槽会带动安装母杆。删除安装母杆会删除对应导槽。
  5. 闭合回路：选择“闭合回路”，依次点击已有节点或空白处，至少三个顶点后点回起点、按 Enter 或点击“闭合回路”按钮。默认每条边是独立连杆、顶点保持铰接。一次 Esc 取消草稿，第二次回到选择。需要刚性板件时单独选择“整体刚性构件”；点击已有三角形的顶点也能合并其边。构件属性中的“释放为独立杆件”可恢复铰接。
  6. 设计凸轮：点击顶部“凸轮设计”打开独立窗口，选择直动或摆动从动件。参数化设计可修改基圆、滚子、升程 / 摆角、运动规律与推程 / 休止 / 回程角；安装参数可调整导轨偏距、方向或摆杆支点与长度。切到“手绘轮廓”，沿紫色轮廓按住拖动，自动闭合；可平滑、撤销笔画并预览运动。可生成新机构、加入当前固定输入轴，或从凸轮属性再次打开窗口更新。拖动轴心会带动整套凸轮，滚子及摆杆支点的位置在设计窗口修改。两个凸轮示例均可仿真、观察曲线和导出。
  7. 轨迹合成：点击顶部“轨迹合成”打开独立窗口。选择现有铰点、杆上点或伸出端并提取轨迹，也可手绘、拖动控制点、平滑或导入目标轨迹文件。选择四杆、曲柄滑块、齿轮联动五杆、行星齿轮或自动比较，设置杆长范围、目标 RMS 和搜索精度；四杆和齿轮联动五杆可锁定两个固定支点。闭合轨迹生成整周回转机构，开放轨迹生成沿目标往返的区间摆动机构。求解后比较候选的 RMS、最大采样偏差和实际运动，再应用到画布；橙色虚线保留目标，彩色轨迹来自机构仿真。未达到目标误差的候选仍会明确标注，可深入搜索或修改约束。支持取消、撤销目标修改、目标 / 机构 JSON、偏差 CSV 和对比 PDF；保存后的合成机构可重开窗口继续调整。
  8. 蜗杆传动：示例中的阿基米德圆柱蜗杆（ZA 型）采用圆柱与轴截面直齿简图，蜗轮与蜗杆连接布置。头数 / 蜗轮齿数决定传动比，可在齿轮属性中修改。
  9. 编辑尺寸：在选择工具下点击杆上的数字，输入新长度并确认。也可拖动铰点或编辑属性。
  10. 杆上点：选择“杆上点”后点击母杆任意位置；点会随母杆运动并默认记录轨迹，可在属性中调整连接位置百分比，也可沿杆拖动。
  11. 杆上铰点：选择“杆上铰点”（J）后点击母杆，生成随母杆运动的真实铰点，并直接进入连杆绘制；再点已有铰点或空白处，就能从它引出新杆。母杆保持原长度，铰点的连接位置可按百分比修改或沿杆拖动。新杆需与其他约束配合形成可驱动机构。
  12. 伸出杆：先点击母杆，再点击伸出端，顶部可选垂直或任意侧向。属性中修改长度、相对角度和偏置，端点可拖动。伸出杆与母杆刚性连接，不增加自由度；目前端点用于观测轨迹。
  13. 网格与绘图：网格可独立开关，滚轮缩放时自动调整间距，最小 1 mm。吸附网格采用当前显示间距；绘杆吸附铰点优先。
  14. 仿真调速：画布下方“播放速度”可在 0.1～4 倍之间调节，运行中即时生效，点击“恢复 1×”回到正常播放速度。倍速设置保存在当前浏览器。输入转速 / 摆动频率决定实际运动学数据，播放倍速只控制演示节奏；单步仍推进 2°。
  15. 轨迹与速度：选择铰点，勾选“记录运动轨迹”，运行或点击“绘制一周轨迹”。颜色从蓝到红表示从慢到快，悬停可读取速度及该次经过的输入角度，箭头表示当前位置速度方向。右侧数值单位 mm/s。往返路径可能重叠；不同角度经过同一点时速度可不同。
  16. 切换运动学：右侧“显示量”可选线速度、线加速度或角速度，对应 mm/s、mm/s²、rad/s。角速度属于参考杆；共享铰点可选择相邻杆，逆时针为正。杆上点和伸出端继承母杆角速度。轨迹颜色按大小，悬停保留角速度符号。速度和加速度按当前输入规律计算，包含摆动角加速度及活动导轨的相对运动。
  17. 函数曲线：点击顶部“函数曲线”，可用“X–Y 轨迹”对比节点运动路径，横纵坐标等比例；“分速度 Vx / Vy”同时显示两个方向的速度，实线为 Vx，虚线为 Vy，并保留正负号。横轴可选输入角度、时间或节点的 X 坐标，纵轴可选运动量，可对比最多六个节点。整周旋转计算一周，区间摆动计算一次完整往返，默认用时间横轴；角度横轴保留去程和回程两支，悬停同时显示时刻。转速 / 频率为零时需用角度横轴。不可达区间或奇异位形的数据会断开。
  18. 分享机构：点击“导入机构”旁的“导出”，选择“机构 JSON”（或 Ctrl+S），将文件发给同学；对方点击“导入机构”即可编辑和运行。文件保留结构、尺寸、活动导轨、固连关系、输入模式、范围、当前往返相位和显示设置。已有可见轨迹会在导入后重新计算；曲线可重新绘制。本版保存 v9 文件，需用 2.1 或更新版本打开；v1～v8 旧版机构 JSON 也能导入。
  19. 轨迹约束：在“轨迹合成”中先画轨迹，再点“添加两个固定铰点”，依次放置 O 与 D。可拖动或展开坐标精确调整，锁定时只比较四杆与齿轮联动五杆。支持交换、清除与撤销；目标轨迹文件一并保存铰点和杆长范围。
  20. 绘图辅助：导入底图，在预览中点选两个已知长度端点标定比例；可调整位置、旋转与不透明度。选择距离或角度测量后在画布选两点或三点，数值随运动更新。底图及测量随机构 JSON 保存，使用案例设置 v2，需要 2.2 或更新版。导出中的“CAD 几何 DXF”保存毫米坐标的当前杆件、凸轮轮廓、齿轮节圆和开启的轨迹。
  21. 我的案例：导入和导出的案例加入左侧列表，点击即可重新加载。列表最多保存 30 个案例，仅保存在当前浏览器；删除列表项不影响当前机构或已导出的文件。修改案例后需再次导出才能分享新版本。
  22. 统一导出：顶部“导出”集中提供机构 JSON、机构与轨迹 PDF、周期运动数据 CSV、函数曲线 PDF 和曲线数据 CSV。机构 PDF 包含已记录且开启的轨迹，完整轨迹先用“绘制一周轨迹”或“绘制往返轨迹”。PDF 为 A4 横向图像版；运动数据按驱动相位每 1° 采样，含输入角度、相位、时间、坐标、速度、加速度、角速度和约束误差。
  23. 自由度：机构概况显示 F = 3n − 2Pₗ − Pₕ、构件数及运动副数。复合铰链按 k − 1 计数；铰接滑块另计构件，与杆固连的滑块合并计数。几何自由度另由初始位形 Jacobian 秩估计。
  24. 齿轮与连杆：选“齿轮”，先点轴心（空白处默认固定轴），再点偏心点。也可选一根现有杆的两端，将齿轮固连在该杆上；偏心点可继续连接杆件。分度圆直径 d = mz，与偏心距分别设置。同轴复合齿轮重复选同一轴心和同一偏心点。
  25. 啮合：选“啮合”后点两只齿轮；外啮合反向、内啮合同向，蜗杆需先选。定轴啮合会对齐第二个轴的中心距。活动轴心先用连杆或杆上铰点连接到行星架，再在啮合栏选择行星架；两个轴心都应在该架上。
  26. 轮系与传动比：右侧显示每个构件相对于输入的总传动比、转速，以及各对啮合的方程。行星架可选择参考杆作为角度输入，齿圈可用固定铰点工具解除轴向参考点的固定，观察自由度变化；自由差动轮系需要第二项约束。
  27. 完整轨迹：减速轮的轨迹往往需要输入转动多周。右侧可设置 1～300 输入圈，或采用可确定的完整轮系周期。累计输入角度保存到分享文件；函数曲线使用累计角度，不把多周数据折叠到一周。
  28. 蜗轮蜗杆与齿形：蜗轮蜗杆在此为正交轴传动的平面示意，按头数 / 蜗轮齿数计算转速，正方向在啮合属性中指定。蜗杆的自由度按等效轴约束统计。齿形为教学示意，未计算真实渐开线、齿隙、干涉、接触力或三维实体。
拖动铰点会重新确定相邻杆长。修改杆长会保持其他尺寸并尝试闭合。仿真中开始编辑会把当前位形作为新的初始位置。编辑机构或转速会清空旧轨迹。

快捷键：V 选择 · P 铰点 · G 固定铰点 · L 连杆 · C 闭合回路 · S 滑块 / 导轨 · J 杆上铰点 · T 杆上点 · E 伸出杆 · F 适应画布 · 空格运行/暂停 · Delete 删除 · Ctrl+Z 撤销 · Ctrl+Y 重做 · Ctrl+S 导出机构 JSON。一次 Esc 取消当前绘制步骤，连续第二次 Esc 回到选择 / 拖动。滚轮缩放，右键或中键平移。
