# 机构工坊 · JiGou Workshop 2.3

中文平面机构设计与运动仿真工具。支持凸轮设计、轨迹逆向合成，可直接在浏览器中离线使用。

![机构工坊](docs/界面预览_使用说明_主界面_2.3.png)

## 开始使用

1. 从 [Releases](https://github.com/HollandBC/jigou-workshop/releases) 下载离线包，或点击 **Code → Download ZIP** 下载源码，解压后使用。
2. 用 Edge 或 Chrome 打开 **机构工坊_离线版.html**，无需安装或联网。
3. 选择内置示例运行，或从空白画布搭建；用机构 JSON 保存和分享设计。

## 主要功能

- **绘制与仿真**：连杆、铰点、滑块、齿轮及蜗杆，支持轨迹和运动量分析。
- **凸轮设计**：参数化或手绘轮廓，支持直动与摆动从动件。
- **轨迹合成**：从已有轨迹或手绘曲线搜索四杆、曲柄滑块、齿轮联动五杆、行星齿轮候选，比较误差并检查完整周期。
- **固定铰点约束（2.3）**：画好轨迹后添加 O、D 两点，可拖动、输入坐标、交换及撤销；锁定位置求解四杆或五杆，目标文件保留约束。
- **辅助与导出**：底图标定、动态测量、函数曲线，以及 JSON、CSV、PDF、DXF 导出。
