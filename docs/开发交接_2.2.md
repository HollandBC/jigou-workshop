# 机构工坊开发交接：2.2

用户授权查阅 Linkage、对比并自主补充。本版查阅 David Rector 的官方 Linkage 3.16 手册及在线帮助，选取“图纸参照 → 标定搭建 → 动态量测 → CAD 交接”流程，增加底图、距离 / 角度测量和毫米 DXF。功能对比见 [对比记录](Linkage功能对比与2.2补充.md)，以 [2.1 交接](开发交接_2.1.md) 为基线，既有绘图、仿真、凸轮、蜗杆、四类轨迹合成和曲线保持。

- 软件 **2.2**；机构结构仍为 **v9**，兼容 v1～v8。普通案例设置 v1；带底图 / 测量的案例设置 **v2**，需要 2.2 或更新版。目标轨迹仍为 v1 / mm。
- 离线入口 `机构工坊_离线版.html`；18 个内嵌脚本，无外部运行依赖。发布包 `G:\机械创新设计\机构工坊_v2.2_源码离线版与使用说明书.zip`。
- 22 个内置案例、35 份可导入机构、6 份目标轨迹；新增 `绘图辅助_底图标定与动态测量.机构.json`，参考图 `examples/参考底图_四杆.png`，静态 CAD 示例 `output/教学四杆_毫米几何_2.2.dxf`。
- 新版说明书 **14 章、20 页**，第 14 章覆盖新增完整流程；HTML 内嵌 8 张图，软件帮助提供 HTML / PDF 入口。

`drafting.js` 实现绘图辅助数据验证、清理、比例计算、当前位形量测、SVG 标注和独立 DXF writer；`draftdesigner.js` 提供独立“绘图辅助”窗口和主画布两点 / 三点选取。底图输入 PNG/JPEG/WebP，最长边缩到 1920 px，以 JPEG 内嵌；宽度标定按真实距离 / 像素间距计算，保持中心与旋转。世界 Y 轴向上，图片单独翻转以避免颠倒。测量绑定真实观测点 ID，角度按第一点→顶点→第三点计算 0～180° 小角，退化射线返回未定义。删除关联点时清理测量，撤销恢复。

案例 v2 的 `case.drawing` 保存 `{version:1,background,measurements}`。底图包含 data URL、像素尺寸、中心、毫米宽度、旋转、opacity 和 visible；测量包含 id、name、type、points、visible。不向机构约束模型添加字段，不改变自由度。自动保存改为案例封装，仍读取旧的原模型；历史条目包含模型与辅助绘图，共享不可变图像字符串以避免重复拷贝。导入上限为 12 MB，以容纳内嵌底图；旧文件和损坏文件保护保留。

DXF 为 R2000 / AC1015，`$INSUNITS=4`。输出当前世界坐标的 LINE、CIRCLE、LWPOLYLINE 和 TEXT，图层为 LINKS、JOINTS、GUIDES、CAM_PROFILE、GEAR_PITCH、TRACES、MEASUREMENTS、LABELS。凸轮按真实轴角转动并闭合采样轮廓；齿轮为节圆。轨迹与尺寸开关生效；图片不进入 CAD，英文编号标签避免依赖中文 CAD 字体。格式定义及边界见对比记录与说明书。

验证：**150 项 Node.js 检查**（新增 7 项绘图辅助验证），**13 组软件浏览器检查 + 1 组手册浏览器检查**。新增 UI 测试覆盖实际导图 / 点选标定 / 非法参数回退 / 附着点选择规则 / 动态角度 / 自由度 / 撤销重做 / 保存重开 / 自动恢复 / 隐藏删除 / PDF 和 DXF / 双 Esc / 390、320 px / 零脚本错误。全部旧功能回归通过。独立 ezdxf 对 8 份 DXF 读取审计，毫米单位，零错误、零修复；该校验库只在 tmp 使用，不是软件运行依赖。

改动后运行 `node --test tests/*.test.cjs`、`node tools/build.cjs`、`node tools/verify-release.cjs`。新 UI 为 `tools/browser-check-drafting.cjs`，既有脚本同 2.1；使用隔离 Edge、qa=1 和独立端口。文档由 `tools/build-manual.py` 生成，并用 Poppler 渲染检查。详细记录见 [验证记录](验证记录.md)。

底图只恢复等比例，不能校正透视；测量不锁定机构；DXF 是静态几何，不能恢复机构运动约束，也不是加工齿形或零件外形。继续保持既有单输入几何 / 运动学范围，曲线导轨、链传动、多输入执行器、零件展开与视频功能另行设计。
