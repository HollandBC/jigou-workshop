# 机构工坊开发交接：2.1

用户要求为轨迹合成新增两类候选，并交付使用说明书与案例教程。本版增加 **齿轮联动五杆** 和 **行星齿轮轨迹机构**，保留四杆与曲柄滑块；自动搜索覆盖四类。以 [2.0 交接](开发交接_2.0.md) 为基线，既有绘图、凸轮、蜗杆、曲线、导出与回路操作继续保留。

- 项目：`G:\机械创新设计\机构工坊`。软件 **2.1**；机构文件 **v9**，兼容读取 v1～v8；目标轨迹仍为 `jigou-trajectory v1 / mm`。
- 入口：`机构工坊_离线版.html`，或源码 `index.html`。离线版含 16 个内嵌脚本，不依赖网络和第三方运行库。
- 发布包：`G:\机械创新设计\机构工坊_v2.1_源码离线版与使用说明书.zip`。
- 22 个内置示例；`examples/` 有 **34 份**机构文件，包括新增三份齿轮合成案例和两份从零搭建教学案例；`examples/轨迹目标/` 有 **6 份**目标轨迹。

`synthesis.js` 增加两类解析姿态、离散整数齿数组合、连续尺寸与安装相位搜索、真实模型建立和源机构初值恢复。五杆通过两个固定轴上的外啮合齿轮约束两曲柄；行星候选使用固定内齿圈、输入行星架和带偏心输出点的行星轮。两者均调用现有齿轮约束与机构求解器，要求自由度 F=1，并通过完整周期采样。齿数比需要 1、2 或 3 圈输入才能回位时，预览、运动学曲线、轨迹提取和保存均按完整周期计算；开放目标采用真实往返驱动。

自动搜索保留每类可行代表，再补充低误差候选，最多六个。窗口显示齿数、周期圈数、杆长顺序、RMS 与最大采样偏差。固定支点限制支持四杆和五杆，其他两类给出明确提示。杆长范围约束活动杆及四杆 / 五杆机架，不代表内齿圈外径。应用后生成真实杆件、齿轮与单输入机构，保存 v9 保留目标与合成设置。

说明书有 **13 章、17 页**，包含四杆与曲柄滑块从零搭建、杆上点和伸出端、滑轨与齿轮、直动 / 摆动参数化凸轮、手绘凸轮、已有轨迹提取、手绘目标、四类逆向合成、完整周期、曲线、文件分享、案例导航和快捷键。软件帮助窗口提供入口。
