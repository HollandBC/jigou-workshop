## 数据与求解分离

编辑模型只保存初始坐标、连接关系和约束参数。仿真帧是另一份坐标映射，求解器不会修改传入模型。界面开始编辑当前仿真位形时，才将该位形转为新初始坐标。

所有坐标采用右手平面坐标：X 向右，Y 向上，角度从 X 轴逆时针增加。SVG 视图在绘图层翻转 Y 轴。

模型示例：

```json
{
  "format": "jigou-workshop",
  "version": 9,
  "name": "示例",
  "nodes": [
    {"id":"A","name":"A","x":0,"y":0,"fixed":true,"trace":false},
    {"id":"B","name":"B","x":40,"y":0,"fixed":false,"trace":true}
  ],
  "links": [
    {"id":"L1","name":"曲柄","a":"A","b":"B","length":40,"color":"#3877e8"}
  ],
  "sliders": [],
  "attachments": [],
  "bodies": [],
  "gears": [],
  "meshes": [],
  "cams": [],
  "synthesis": null,
  "motor": {"link":"L1","pivot":"A","initialAngle":0,"rpm":12}
}
```

ID 为 ASCII 字母开头，只含字母、数字、下划线与连字符，长度不超过 40。名称允许中文，界面渲染时统一转义。`model.validate` 重建已验证对象，不保留未定义字段。

导轨基本定义仍为 `{id,node,origin:{x,y},angle}`；不指定 guide 时为机架上的无限直线。v5 可增加 guide、block、blockAngle 和绘图长度 length，支持活动导槽和固连滑块，详细定义见下文 0.8。length 不限制行程。

v4 节点可以增加 `onLink: {link:"L1",t:0.5}`，表示固定在母杆 A/B 两端之间的可连接铰点。它仍在 `nodes` 中，独立杆可直接引用其 ID。坐标须满足 `P=(1−t)A+tB`，t 在开区间 (0,1) 内，距两端至少 0.1 mm；验证拒绝缺失母杆、把自身作为母杆端点、循环母杆依赖和不一致坐标。1.1 时 v1～v6 文件迁移到 v7；2.0 将 v1～v7 文件统一升级为 v8。旧格式不能携带新约束，避免旧阅读器丢失约束。

## 2.1 齿轮联动五杆与行星逆向候选

`fivebar` 以两固定轴间距归一化，参数包括两曲柄、两闭合杆、输出点比例与法向偏置、第二曲柄初相位及离散齿数组合。两曲柄角度满足外啮合约束，第二角 = beta − z1/z2 * theta；用圆圆交点求闭合端，分别搜索两个分支。两轴中心距与同模数节圆之和严格一致，四活动杆加机架经一个高副约束得到 F=1。可以锁定两个固定支点。

`planetary` 为固定内齿圈、输入行星架、行星轮偏心点。归一化行星架长为 1，输出为 (cos theta,sin theta) + e*(cos(beta+k*theta),sin(beta+k*theta))，k=1−zRing/zPlanet。模数按两轮节圆半径差确定；固定齿圈方位参考杆两端固定。当前齿数配对分别为五杆 20/20、40/20、20/40、60/20、20/60；行星 24/12、36/12、48/12、60/12、30/12、24/16、24/18。离散索引与连续尺寸一起优化，模数须满足已有 0.1～100 范围。

完整回位圈数为齿数配对约分后的分母，写入 motor.sampleTurns。闭合解析曲线、弧长角度插值、最终实际位置和 solver.sweep 均覆盖完整 1～3 输入周；开放目标仍生成一次完整往返。预览的 0～360 周期相位按完整圈数换算成输入角度，并采用驱动方向。齿轮 SVG 与主画布共用 gears.svg，视口包括节圆边界。开放候选显示一次往返，避免误标为一个回转输入圈。

自动模式在约束允许时比较四类，固定两支点只比较四杆 / 五杆。每个可行拓扑先保留一个代表，再按 RMS 补足最多六个候选，避免加入低误差候选时挤掉另一类型。多代档案另保留各任务局部细化结果。新增 inferGeared 可从生成模型恢复解析初值和当前相位；存盘只保留目标和设置。

应用版本 2.1，机构 v9；读 v1～v8 升级为 v9。v8 原目标格式继续有效，旧编号携带 family=fivebar/planetary 时拒绝。已有 gears、meshes、attachments、motor 数据结构无需新增物理约束类型。34 份机构与 6 份目标通过逐一读取、文件往返和完整周期检查。

新增 tests/synthesis-geared.test.cjs 的 9 项验证采用独立圆交、内滚公式、未知尺寸目标、角速度齿比、多圈非回位 / 最终回位、锁定支点、开放 / 反向、初值与 v9 分享。总计 143 项。12 组软件浏览器及一组手册浏览器检查通过。手册由 tools/build-manual.py 生成可搜索单文件 HTML 与 17 页 A4 PDF，中文字体嵌入，逐页渲染核对。

几何背景：[齿轮联动五杆原始研究](https://www.sciencedirect.com/science/article/pii/0094114X78900472)、[MathWorld 内滚轨迹](https://mathworld.wolfram.com/Hypotrochoid.html)。实现独立编写。齿轮外观和机构模型用于教学与运动学，不计算制造干涉、碰撞或承载。

## 2.0 逆向轨迹合成（历史基础实现）

新增 `src/synthesis.js`（纯几何、搜索、模型生成与持久化）和 `src/synthdesigner.js`（独立窗口、目标编辑、候选预览和导出）。应用仍无运行依赖；离线版内嵌 16 个脚本。`tools/verify-release.cjs` 只读检查 29 份机构、三份目标、完整周期及源码与离线页一致性。

四杆以机架长度归一化，搜索曲柄、连杆、摇杆长度与连杆上的输出点（沿杆比例和法向偏置），分别求两个装配分支。曲柄滑块以曲柄长度归一化，搜索连杆长度、导轨偏置与同样的输出点坐标。圆圆相交及导轨交点均解析计算；整周模式预筛闭合条件和接近奇异的尺寸。开放模式另外搜索输入角度起点和跨度，生成正弦往返驱动。

目标去除重复点、可选邻域平滑，再按弧长重采样；开放目标保留端点。搜索阶段每条机构曲线用 96 个角度点，最终用 360 个角度点估计弧长对应关系，随后在对应角度重新解析计算实际位置，用这些实际位置报告 RMS / 最大采样偏差。闭合目标枚举循环移位，可选反向顺序；未锁定支点时用最小二乘相似变换求统一缩放、安装转角和平移。锁定四杆两支点时直接确定安装变换，不能通过整体移动降低误差。最终世界尺寸须满足杆长限制，四杆包含机架长度。

采用有种子的差分进化、多初始尺寸与局部坐标细化；快速 / 标准 / 深入分别使用 40/64/90 个体、90/220/480 代及 32/48/64 个误差采样点。不同拓扑和装配分支分别搜索，保留尺寸有区别的候选；自动模式有可行解时保留两类拓扑代表。来源机构符合模板时可作为初值，但不是直接复制结果；独立未知尺寸算例验证无初值搜索。搜索分批在约 22 ms 后让出主线程，支持 AbortSignal、进度及取消；搜索是数值近似，不承诺任意曲线的精确解或全局最优。

候选通过 `model.validate` 生成 O/A/B/D、连杆、导轨和输出伸出端 T1，输出与母杆刚性连接。随后 `solver.sweep(model,1)` 检查 361 帧的完整旋转或完整往返，并要求自由度 F=1。预览和应用使用同一个实际求解器，速度 / 加速度仍由真实驱动计算。开放目标拟合单次去程，回程沿相同路径；现有摆动机构提取一个最小角至最大角的行程，避免把往返重叠误判为闭合曲线。多周来源轨迹超过点数上限时按弧长重采样，静止轨迹拒绝。

v8 顶层 `synthesis` 为 null 或 `{version:1,target:{name,source,points},settings:{family,quality,minLength,maxLength,tolerance,allowReverse,closed,smoothing,anchors?}}`。只保存原始目标与设置，不持久化候选、搜索初值或旧误差，手动编辑机构后不会显示过期误差。v1～v7 导入统一升级为 v8；旧版本号携带合成数据拒绝。目标单独采用 `jigou-trajectory` v1，单位必须为 mm。采样误差 CSV 使用目标 / 实际位置及距离，PDF 为单页 A4 横向。

## 1.1 凸轮接触与独立设计窗口

新增 `cams.js` 和 `camdesigner.js`。前者可通过 Node.js 独立检查轮廓、接触位置及约束；后者负责独立 dialog、参数输入、运动预览和真实 pointer 手绘。无新增应用运行依赖，离线页内嵌 14 个脚本。

v7 顶层必须有 `cams` 数组，最多 10 个。每项通过 `center / link / node` 引用固定轴心、相位参考杆和从动件节点。`type` 为 translate / oscillate；`source` 为 parametric / drawn。直动额外引用机架导轨 `guide`；摆动额外引用固定支点 `pivot` 及从动杆 `followerLink`。参数包含 baseRadius、rollerRadius、lift / swing、rise / dwell / fall、law、axisAngle / offset、armLength、side 和 zeroAngle；缺省值见 `cams.defaults`。手绘额外保存 360 个 1° 半径采样 `radii`。旧 v1～v6 文件可升级，但旧版本号携带凸轮约束会拒绝，防止旧阅读器忽略接触关系。

参数化直动先求滚子中心节曲线：沿导轨的距离为 `sqrt((Rb+Rr)^2-e^2)+h*f(theta)`。摆动先由轴心、支点、杆长及基圆滚子半径求基础接触角，再按所选分支施加摆角规律。把各相位的滚子中心反转 `-theta` 得到凸轮坐标系节曲线，以法向向内偏移滚子半径得到实际轮廓。画布、设计窗口、示例缩略图和 PDF 使用同一轮廓。

手绘轮廓采用绕轴单值半径，使用周期 C2 三次样条闭合，保存采样而不保存屏幕坐标。滚子中心接触曲线按实际轮廓的外法向偏移半径生成；直动求这条曲线与导轨的交点，摆动求其与摆杆圆的交点，并检查指定分支。位置用扫描加二分求交；一、二阶导数采用角度中心差分。因此手绘输出由实际接触计算，其加速度是平滑轮廓的数值导数估计。滚子为 0 时直接接触实际轮廓。

`cams.equations` 在求解器中增加一个高副约束：直动为沿导轨位置减目标位移，摆动为实际杆角减目标角（以杆长缩放）。相位角通过参考杆 atan2 梯度进入同一 Jacobian；既有直线导轨或摆杆长度补足其余几何约束。`cams.seed` 为已知轴相位提供直接位置传播；数值求解仍检查全部约束，可从输出节点连接下游杆件。`cams.forcing` 加入 `s''*omega^2+s'*alpha` 和相位 / 摆杆角度的坐标二阶项，运动学、曲线及 CSV 仍使用真实驱动转速或摆动频率。

局部节曲线曲率筛查过大的滚子半径；手绘按 2° 检查整周接触、分支及明显输出跳变。不计算压力角、制造公差、接触力、弹簧或高速脱离。尖顶与滚子几何接触均假定持续成立；局部筛查不能替代制造检验。

`cams.install` 可生成新轴或共用现有固定输入轴。`update` 保持输出节点 ID，重建所属导轨 / 摆杆，已有下游连接若无法闭合则通过 `app.change` 回滚。安装及编辑纳入统一历史、验证、自动保存和案例文件。拖动凸轮轴心整体移动轴、从动件、导轨或摆杆支点；共用齿轮轴时先沿既有齿轮网络平移。受凸轮控制的滚子、相位点和摆杆支点不允许破坏安装关系的自由拖动。

`model.mobility` 将每个凸轮接触计一个等效高副，凸轮与相位参考杆作为同一构件；两类单凸轮示例均 `F=3*2-2*2-1=1`。新增 camtranslate / camrocker，内置案例共 22 个；examples/ 共 26 份 v7 文件，含实际手绘后保存的偏心圆。

蜗杆示例使用 ZA 圆柱简图：根据两轴中心向量确定平面示意中的蜗杆轴向，绘制圆柱、轴截面直齿和螺旋纹。默认中心距与模数 / 蜗轮齿数编辑均采用 `a=(d1+d2)/2`，修复分离布局。头数与齿数角度约束及完整 40 输入周周期保留。该布局是正交轴传动的平面简图；不会生成制造用三维齿面。

几何依据：[METU 凸轮反转与包络](https://ocw.metu.edu.tr/pluginfile.php/5791/mod_resource/content/8/ch8/8-2.htm)、[METU 滚子曲率](https://ocw.metu.edu.tr/pluginfile.php/5791/mod_resource/content/8/ch8/8-4a.htm)、[KHK 蜗杆技术资料](https://khkgears.net/pdf/worm-tech.pdf)。实现与源代码均为本项目独立编写。

`tests/cams.test.cjs` 用独立摆线导数、偏心圆的直线 / 圆交点、滚子包络距离、坐标扰动、下游连杆、正反转及零速、类型切换与约束拖动验证。`tools/browser-check-cams.cjs` 实际按鼠标绘制轮廓，检查预览、平滑、应用、保存重开、轨迹与 PDF / CSV。验证结果见 `docs/验证记录.md`。

## 1.0.3 坐标与分速度对比

src/curves.js 的 series 支持 axis='x'：每条曲线的横坐标来自该观测点自身的 X 坐标，按驱动采样顺序连接，不按 X 排序、不删除闭合端点。与 metric='y' 组合时形成 X–Y 轨迹。layout 按有效坐标对确定范围并留出边距，不强制包含远离轨迹的原点；X–Y 模式扩大较窄的坐标范围，使横纵轴每 mm 对应相同像素数，直线等退化范围也可显示。坐标刻度采用 1 / 2 / 5 倍数量级，整周角度轴保留 60° 刻度。

metric='components' 将每个节点展开为 vx / vy 两条曲线，共用节点颜色，Vy 使用 7 4 虚线。每条曲线保存 pointId、pointName、metric、dash、angle / phase / time 等信息，ID 在节点 ID 后增加分量后缀。旧单量曲线 ID 和 CSV 格式保持兼容。无运动学解时分量为 null，位置仍可用于坐标对比；真实输入转速决定分量和时间，播放倍速不参与计算。

src/app.js 增加快速对比按钮，X–Y 预设设为 x / y，分速度预设设置 components，并在从 X 坐标切换时采用时间横轴（零转速采用角度）。X 坐标模式悬停按二维距离查找最接近的采样点，再显示同一帧各条曲线的坐标与标记；不会把不同节点的 X 当作公共横轴。手机提示框置于图下，避免多行读数被窗口裁切。

## 1.0 齿轮与角度约束

新增模块 src/gears.js，在 model 后、drive / solver 前加载。它负责验证、轴系编辑、展开角度、传动关系、SVG 示意与示例；求解器和视图调用其接口。应用仍无第三方运行依赖。

v6 顶层必须有 gears 与 meshes 数组。齿轮示例：

```json
{"id":"G1","name":"主动齿轮","kind":"spur","center":"O","link":"L1","teeth":20,"module":2,"color":"#3877e8"}
```

kind 是 spur / ring / worm / wheel；蜗杆增加 starts（1～8）。齿轮轴心须是参考杆端点，参考杆另一端定义固连偏心点，参考杆长度不等于分度圆半径。齿轮复用连杆的方位与角速度，不增加虚构的独立自由度；同轴固连齿轮引用同一 link。自动生成参考杆可标 rotor，保留属性编辑与连接能力，省略画布杆长标注。最多 30 齿轮、50 啮合，齿数 8～300、模数 0.1～100 mm；这是程序范围，不代表可制造范围。

外啮合定义 {id,a,b,type:"external"}，内啮合 type 为 internal；蜗杆须 A、蜗轮须 B，type:"worm" 并有 direction:±1。活动轮系增加 carrier:linkId；两个轴心必须安装在该架上。齿轮模数一致，定轴需两个固定轴心；平面齿轮按分度圆验证中心距，worm 不把示意轴距当作真实三维啮合尺寸。

外啮合：za(θa−θh)+zb(θb−θh)=初始常量。内啮合：z外(θ外−θh)−z圈(θ圈−θh)=初始常量。定轴时 θh=0。蜗杆：头数×Δθa−direction×z蜗轮×Δθb=0。残差按半径 / 最大齿数缩放为长度量纲；Jacobian 使用每根参考杆 atan2 方位角的解析导数。加速度 RHS 包含方位角曲率项 eta，不用动画差分。与旧长度、仿射铰点、导轨约束共同求解。

gears.ratios 用角速度线性方程与已知输入 / 固定成员进行消元，只返回可唯一确定的构件比值。自由差动只知道主动输入，不推断其他自由转速；几何求解器仍通过秩拒绝欠约束运动。通过非线性连杆间接驱动时，gears.train 使用瞬时运动学结果计算并标注瞬时 i。零输入速度或输出瞬时停转不产生伪有限传动比。

帧坐标映射的非枚举 __angles 保存连续方位角，不进入节点列表或 JSON。已确定的常比轮系按累计输入角度预测各轴展开角与初值，避免跨零、多周、高减速比时的齿距分支误选。每次编辑把当前位形作为新初始相位；保存案例则保留累计输入角度，由模型初始位形重新求解恢复。

motor.sampleTurns 是 v6 的观察圈数（1～300），不改变输入速度；摆动模式仍采样一个往返周期。自动完整周期为各可确定角速度比的最简分母最小公倍数，上限 300 圈。涉及未知 / 瞬时比时由用户指定观察圈数。drive.plan 限制最多 3601 帧，保留端点和时间。gears 存在时 curves 不进行 0～360° 重排，使用累计角度。

简单行星示例：40 齿太阳轮、20 齿行星轮、80 齿固定齿圈，行星架长 60 mm；ω太阳=3ω架，ω行星=−ω太阳。仅绘制一个行星轮以清楚展示约束；使用多个行星轮可能引入重复约束，公式计数与实际秩应分别显示。扑翼示例两轮各 20 齿、m=3、轴距 60 mm、偏心 8 mm；左右摇杆的翼臂采用 t=0、along=0、normal=±115，保持镜像且向两侧伸出。

每对啮合记一个等效高副；齿轮与其参考杆作为一个构件，同轴共杆只计一次。蜗轮蜗杆是正交轴示意，界面中的平面自由度是等效轴约束统计，不是空间机构的通用自由度公式。SVG 齿形为离散示意，未求渐开线与接触相位，也无干涉、载荷、效率或自锁判定。

设计公式校核参考：[KHK 内齿轮与行星轮系资料](https://khkgears.net/pdf/internal-tech.pdf)、[KHK 蜗轮蜗杆头数与传动比说明](https://khkgears.net/product-category/worm-gear-pair/)。源代码和示例为本项目独立实现，没有复制原软件。

## 求解管线

1. 固定点采用初始坐标。有固定支点的角度输入端点按 `pivot + length * (cos(angle), sin(angle))` 直接计算，不进入未知变量。无固定支点时输入杆两端都作为未知数，额外建立方位角约束。
2. 其他活动铰点的 X/Y 为未知数。上一帧坐标用作选解偏好和数值初值。
3. 检查 Jacobian 秩。驱动后仍有局部未约束自由度时，默认拒绝求解。
4. 根据已知点尝试圆圆求交、圆与导轨求交，选择接近上一帧的解；母杆两端已知时直接按仿射关系计算杆上铰点，迭代传播新已知位置。
5. 若仍有残差，使用带阻尼的 Gauss–Newton / Levenberg–Marquardt 形式更新全部未知坐标。线性系统采用带主元的高斯消元。
6. 每次返回前重新计算所有连杆、杆上铰点和导轨残差。最大绝对残差必须 ≤ `1e-5 mm`，否则返回失败，界面保留最后成功位形并暂停。

残差与导数：

- 连杆：`r = hypot(xa-xb, ya-yb) - L`；对 a 的导数是 `(dx/d,dy/d)`，对 b 为相反数。
- 杆上铰点：X/Y 分别建立 `r = P − (1−t)A − tB`；三个节点在对应坐标上的导数依次为 `1,t−1,−t`。
- 固定导轨：`r = -(x-ox)*sin(alpha) + (y-oy)*cos(alpha)`；导数为 `(-sin(alpha),cos(alpha))`。

驱动后的固定坐标不参与迭代，因此固定铰点和旋转输入端点精确满足其定义。每次 UI 角度变化按至多 2° 分步推进；播放按驱动相位分步，周期导出默认每 1° 相位采样。数值迭代目标为 1e-8 mm，最终接受标准仍为 1e-5 mm。只有满足全部约束才接受一个帧。

## 扩展接口

`JiGou.solver.solve(model, angle, previousPositions)` 返回：

```js
{ ok: true, positions: { A: {x: 0,y: 0}, /* … */ }, residual, iterations, method }
// 或
{ ok: false, code: 'underconstrained' | 'infeasible', message, residual }
```

`analyze(model)` 返回当前位形的 Jacobian 秩、驱动前自由度和驱动后剩余自由度；`sweep(model, step)` 返回所选输入模式的完整周期帧列表，遇到失败立即停止。求解器不依赖浏览器，可以直接用于命令行分析或未来的桌面应用。

## 0.2 速度与自由度

`solver.velocities(model, positions)` 对连杆长度、杆上铰点和导轨残差求时间导数。固定节点速度为 0，曲柄端速度为 `omega * (-dy, dx)`，`omega = rpm * 2π / 60`。其他节点解约束 Jacobian 的线性系统，输出 `{ok:true,nodes:{id:{x,y,speed}},residual}`，其中 x/y 是速度分量，单位 mm/s。欠约束、未闭合、奇异或不兼容的位形返回失败，不用动画帧间位移冒充物理速度。

轨迹样本保存 `{x,y,angle,vx,vy,speed}`，不可用速度记为 null。按全体当前轨迹的最大已观测速度形成色标，32 个颜色桶合并成 SVG 路径，避免每个样本创建独立 DOM 元素。选择的轨迹节点显示当前速度箭头，长度按色标归一化，真实数值独立显示。CSV 的不可用速度留空。

`model.mobility(model)` 返回构件法的 n、转动副、移动副、低副、高副和自由度。独立活动杆、整体构件、铰接滑块分别计数，固连滑块并入连接杆，复合铰链按不同构件数 k − 1 计数，固定机架合并为一个参照。构件边和内部实杆不重复计入 n；仅属于该构件的点不计转动副。高副目前为 0。孤立活动点另行提示；公式计算不替代几何 Jacobian 秩检测。普通三角回路不自动合并刚体。

## 0.3 附着结构与二阶运动学

JSON 文件版本提升至 2，`model.validate` 同时接受 v1 并迁移。新增 `attachments` 数组，示例：

```json
{"id":"T1","name":"伸出端","link":"L2","t":0.5,"along":0,"normal":50,"arm":true,"trace":true}
```

母杆方向单位向量为 u，左侧法向为 n。连接点是 `anchor = A + t*(B-A)`，端点是 `anchor + along*u + normal*n`。t 的范围为 0～1；点模式 arm=false 时 along/normal 均为 0，伸出杆模式长度最低 0.1 mm。它们是母杆的刚性附着物，不进入独立节点方程或自由度计数。母杆删除时 UI 联动移除附着结构，撤销可恢复。

`model.positions` 合并独立节点与附着点坐标；`model.observers` 提供统一观测列表。计算仍使用独立节点，避免把观测点误当欠约束自由节点。附件 ID 不得与独立节点冲突，导入无效母杆引用会被拒绝。

`motion.analyze(model, positions)` 先求一阶速度，再求二阶长度约束：`u·(aA-aB) = -(‖vA-vB‖² - (u·(vA-vB))²)/L`。固定点加速度为 0，输入曲柄端为 `-omega²*r`，导轨二阶右端为 0。解同一组 Jacobian 的加速度系统，并核对残差。

母杆的 `omega = cross(r, vB-vA)/‖r‖²`，`alpha = cross(r, aB-aA)/‖r‖²`。附着点相对 A 的位置为 q：`vP = vA + omega*Jq`，`aP = aA + alpha*Jq - omega²*q`。J 表示平面逆时针 90° 旋转。该实现用于恒定 rpm 的旋转输入；不能直接推广为变速驱动而忽略输入角加速度。

结果包含 nodes / links / attachments 三组数据。运动学样本同时记录速度、加速度和相邻杆的角速度，切换显示量或共享铰点参考杆无需重跑。角速度色标取绝对值，读数保留正负号；孤立点没有角速度参考杆。当前位置运动学缓存按模型对象和仿真坐标对象失效，拖动和编辑会主动失效。

## 0.5 示例入口与 Jansen

内置案例统一放在 `examples-dialog` 原生模态窗口内；顶部 `examples-btn` 打开窗口。选择案例后关闭窗口并调用原 `replaceModel`；若用户取消切换则重新打开选择窗口，保持当前机构。打开示例时暂停播放，选择后焦点回到按钮。切换案例默认观察第一个追踪点，导入分享案例则采用其保存的观察设置。

`model.example('jansen')` 构造单腿机构。固定点 O=(0,0)、A=(38,7.8)，曲柄 A-B 长 15；初始驱动角度 40°。连接与杆长：O-C=41.5，O-D=40.1，C-D=55.8，B-C=50，O-E=39.3，B-E=61.9，D-F=39.4，E-F=36.7，F-H=65.7，E-H=49。H 为足端并默认开启轨迹。参数依据 [Wang 与 Hou 的 Jansen 图及公开比例](https://papers.cumincad.org/data/works/att/caadria2018_140.pdf)。

0.6 将上三角 O-C-D、足三角 E-F-H 标记为两个整体构件。连同 5 根独立杆，n=7；O 计 2、A 计 1、B 计 2、C 计 1、D 计 1、E 计 2、F 计 1、H 计 0 个转动副，总 Pₗ=10，F=3×7−2×10=1。H 为构件上的观测点，保留轨迹与运动学功能。几何自由度为 1，驱动后剩余自由度为 0。旧版 11 杆 / 16 副的铰接边表示也得到 1，但不代表实际整体构件口径，已替换。

初始装配分支采用圆圆求交的上 C、左 D、下 E、外 F、下 H；连续运动沿上一帧选择支点，使用现有求解器与运动学模块。不要在没有上一帧或正确装配初值的情况下，一次大幅跨角求解并假定分支不变；界面已有分步推进，整周轨迹逐度推进。

`tests/jansen.test.cjs` 用独立余弦定理对完整一周的全部点逐度比较；检查所有杆长、正反两周连续性、足端支撑段、速度与加速度中心差分及分享往返。

## 0.6 闭合绘图与整体构件

`bodies` 项为 `{id,name,nodes:[有序轮廓节点ID],links:[成员杆ID],color}`。轮廓支持 3～12 点，最多 20 个构件。验证时检查节点、边界、点间距、非零面积及初始边长一致性；`links` 根据轮廓和内部杆重建，同一实杆不能属于两个构件。一般 v1 / v2 文件迁移后 `bodies=[]`；旧标准 Jansen 示例通过严格名称及连接关系匹配补充两个三角构件。v3 显式空构件列表保留用户释放后的选择。

`model.constraintLinks` 将实杆和整体构件的隐藏点间距离合为去重约束列表。隐藏距离来自编辑模型初始形状；所有点对距离固定，使四边及更多顶点不能内部变形。求解残差、解析传播、速度 Jacobian 与加速度右端项均使用相同列表，保证三种运动学计算一致。隐藏约束不进入绘图、连杆数、转动副数或角速度参考列表；整体构件的边共享刚体角速度。

`app` 的 `loopDraft` 仅保存尚未完成的节点引用或新坐标。默认 `hinged`，完成后建立首尾连接的独立杆，复用现有节点与边；已闭合回路不会新增撤销项。显式选择 `rigid` 才增加 `bodies` 定义，支持把已有轮廓合为整体构件。至少三个顶点后点回首点、Enter 或按钮完成；首点附近 14 px 吸附，Esc / 切换工具取消草稿。成功创建在一次 `change` 内完成，所以撤销恢复全部新节点、杆和构件定义。

编辑整体构件的顶点会重算相邻边长和隐式初始距离；单独编辑成员边长禁用，避免边长与刚体轮廓不一致。删除边界节点或边会释放该构件定义；删除内部辅助实杆保持整体刚性。删除构件定义 / 释放按钮仅删除分组，保留独立杆与节点。

视图使用半透明轮廓、蓝色整体选中、构件列表和非铰接观测点标识。`snapshot` 删除绘图草稿并保留已建立的整体轮廓，因此 PDF 和轨迹绘图一致。`tests/bodies.test.cjs` 以矩形板的独立旋转、速度与向心加速度公式检查刚体约束，另验证铰接回路差异、Jansen 副数、文件迁移及坏输入。

画布 SVG 绝对定位填满独立的 `stage-wrap`，编辑栏允许 `min-height:0`。SVG 的 `viewBox` 在重绘时根据画布尺寸变化，但不参与父容器的固有尺寸计算，避免空白画布中的 ResizeObserver / SVG 比例反馈导致页面不断增长。

## 0.7 杆上铰点、曲线与导出入口

`model.addPin(model,link,t)` 创建 `onLink` 节点，端点附近复用端点，同母杆同位置复用已有铰点。新节点的两个未知坐标由两条仿射约束确定，因此仅添加杆上铰点不增加自由度。`mobility` 将它纳入母杆所属构件的节点集合；新独立杆引用该点时才按不同构件数增加转动副。母杆不拆成两个独立构件，整体构件上的母杆仍归属原构件。

速度满足 `vP=(1−t)vA+t·vB`，加速度满足 `aP=(1−t)aA+t·aB`，两条加速度方程的右端为零。残差行排列始终为长度约束、杆上铰点的 X/Y、导轨，速度和加速度计算保持相同排列。嵌套杆上铰点通过拓扑递归传播，验证阶段阻止循环。

`model.syncPins` 在编辑端点或连接百分比时同步所有依赖铰点，再重算受影响的真实杆长。拖动杆上铰点沿母杆投影，不改变母杆长度；以当前仿真位形编辑时也保留仿射关系。`model.prune` 级联删除缺失母杆的铰点、缺失端点的杆以及失效导轨、附件、构件或驱动，整个 UI 修改仍由一个历史快照覆盖。

固定功能只在 `fixed` 绘图工具（G）中修改。它在空白处创建固定节点，也可切换已有节点状态；失效的旋转输入随状态修改移除。杆上铰点工具（J）建立真实节点后，设置连杆工具的起点，让用户继续绘制独立杆。

`curves.sample(model)` 对模型快照求解 361 个位形，不修改编辑模型与画布轨迹。采样角度为 `initialAngle + sign(rpm)·i`（零转速按正方向扫角），时间为 `i/(|rpm|·6)`，单位秒；零转速时间设为 null。每个帧保存位置与完整运动学结果；角度不可闭合时返回已成功的前段及错误说明，不用最后一帧填补数据。

`curves.series` 按节点、显示量、横轴和角速度参考杆抽取数值。完整角度周期规范到 0～360° 后排序；反向时间曲线仍按真实运动方向保留时间顺序。未完整求解的角度按展开角显示。坐标读取不依赖速度是否可解，运动学失败时对应数据为 null。SVG 路径在 null 处断开；悬停显示同一采样位置的各节点值。角速度参考杆必须属于节点的连接杆或母杆，附件始终继承母杆。

UI 最多叠加六个观察点，切换显示量或参考杆只重新抽取数据；模型或转速变化使缓存失效。曲线 PDF 使用与窗口相同的 SVG 和图例，CSV 含 BOM、单位及六位小数，未定义数据留空。曲线选项与采样缓存不写入机构 JSON，导入机构后可重新计算。

导入入口名为“导入机构”。JSON、机构 PDF、运动 CSV、曲线 PDF 与曲线 CSV 都由 `export-dialog` 提供；曲线窗口也进入同一菜单，关闭后回到曲线窗口。机构导出文件名为 `机构名称.机构.json`。Ctrl+S 直接生成 JSON，不需要先打开菜单。

`tests/pins-curves.test.cjs` 用独立圆周、滑块速度导数和仿射运动公式检查新约束，覆盖分支、嵌套、自由度、删除、格式验证、正反向时间轴、角速度和数据断开。`tools/browser-check-v7.cjs` 检查实际绘图、编辑、共享、曲线操作、导出与窄屏入口。

## 0.8 周期输入与活动移动副

src/drive.js 在 model 后、cases 前加载，集中定义角度输入规律与采样计划。motor 保留 link、pivot、initialAngle、rpm，新增可选 mode（rotate / swing），摆动需要 minAngle、maxAngle，可用 initialPhase 保存初始运动方向。pivot 为 null 时控制 link.a→link.b 的方位角；有固定支点时仍沿用从 pivot 指向另一端的角度。旧文件默认 rotate。

驱动角度采用度，omega / alpha 采用 rad/s 与 rad/s²。令 φ 为驱动相位、ν = rpm × 2π/60：

- 旋转：θ = φ，ω = ν，α = 0。
- 摆动：θ = θ中 + A sin φ，ω = A(rad) × ν cos φ，α = −A(rad) × ν² sin φ。

rpm 在 swing 模式下表示往返频率（次/分），在 rotate 下表示转速。drive.plan 每个周期返回 361 个角度、相位、时间及导数；负频率反向推进相位，零频率时间为 null、ω / α 为零。drive.phaseForAngle 在给定 near 时选择最近的去程 / 回程分支。仅由位形无法判断同一角度的往返方向，因此播放、扫周期和曲线明确向 motion.analyze(model,positions,drive) 传入 drive.at 的结果；不传时按初始正余弦分支推断。UI 模式和范围修改先验证完整周期可达，失败则还原。

v5 活动导轨示例：

~~~json
{"id":"S1","node":"B","origin":{"x":45,"y":0},"angle":0,"guide":"L2","length":260}
~~~

origin 是 guide.a 为原点、guide.a→guide.b 为 X 方向的局部沿杆 / 侧向位置，angle 是相对该方向的角度。model.railPose 在当前帧转换成世界 origin / u / n。未设置 guide 时 origin 和 angle 都使用世界坐标。滑块 node 必须独立于导槽母杆的端点及固接铰点；node 可以固定，表示穿过固定摇块的活动导杆。

选择 block 指向与 node 相接的独立杆或整体构件成员杆时，滑块与该构件固连，blockAngle 定义 θblock − θguide（机架导轨 θguide 为常量）。残差增加长度缩放的角度差，使杆件沿导轨平移且锁定相对方向；活动 guide 与 block 必须属于不同构件。默认不设 block 时按铰接滑块建模，允许它与相邻杆相对转动。删除 guide 或 block 母杆后 model.prune 会移除失效移动副。

活动导轨的几何直线残差仍为 r = n·(p − origin)，但 Jacobian 包含母杆转动项，不能仅沿用固定导轨的法向导数。令 a 为母杆首端、z = p − a，g 为母杆角度对两端坐标的导数，q = −u·z：滑块点导数为 n，母杆首端为 −n − qg，末端为 qg。角度固连残差与无固定端的输入残差使用 atan2 的解析梯度。

加速度包含活动导轨的二阶项。令 w 为母杆角速度、η = −2w(Δp·Δv)/|Δp|²，则直线行右端为 2w u·(vp−va) + η u·z + w² n·z；相对角度行的右端为 Lblock(ηguide−ηblock)。这些项由 solver.guideForcing 返回，motion 还加入驱动角加速度。残差行顺序为长度、杆上铰点 X/Y、每条导轨的直线与可选相对角度、最后的可选无固定端输入，速度和加速度使用相同顺序。

mobility 把铰接滑块作为独立构件，固连滑块并入 block 所属构件；机架导轨和活动导轨都各计一个移动副。固定中心的活动摇块仍是活动构件；重复计入固连滑块会错误增加 n。内置九个新机构均为公式与几何自由度 1：双曲柄、双摇杆和三个导杆 / 摇块为单移动副或全转动副类型；正弦、双滑块和双转块是两个移动副类型。位移缩放案例以平行四边形尺寸实现 Q = 2B（参照固定点 O），输入曲柄使完整机构具有单输入自由度。

示例由 model.catalog 统一管理名称、说明和缩略图，视图按实际几何生成 20 个预览。view.fit 包括有限显示长度的导轨端点，避免活动槽线在适配后被裁切。绘图的第一步不写入模型，第二步一次性创建点 / 移动副；取消、撤销与选择工具一致。

curves 使用 drive.plan，摆动 angleCycle=false，保留往返两支的时序；时间横轴为摆动默认值。悬停按横纵坐标选择相应分支，并通过同一个样本索引读取全部对比点。机构 CSV 增加驱动相位和时间列，分享文件保存 case.drivePhase，导入时验证相位对应保存角度。PDF 用当前输入规律及其频率单位描述机构。

tests/guides-drive.test.cjs 采用独立四杆分类、单位向量导数、正弦输出公式、椭圆坐标、交叉导槽坐标和缩放关系验证位置 / 速度 / 加速度，另以中心差分检查解析 Jacobian。browser-check-v8.cjs 覆盖实际移动副绘制、输入模式、范围验证、相位往返分享、曲线导出和窄屏交互。

## 0.9 导轨范围与约束编辑

model.railProjection 把世界坐标投影到当前导轨；railTravel 在每个帧的当前母杆坐标系中统计滑块沿导轨坐标 q 的范围，不使用世界轨迹包围盒替代相对行程。railBounds 把显示段中心置于行程中点，长度为 max(用户最小长度, 已知行程 + 两端 8 mm 余量)，并始终包含当前滑块。导轨的几何约束仍是无限直线，显示端点不成为行程限位。

UI 按模型引用缓存 1° 相位采样的完整周期，未完成周期保留已求解的局部范围。导轨显示范围与轨迹开关无关。拖动过程只更新当前位形的已知范围，松开后重算周期，避免每次指针事件执行整周求解。model.railTravel / railBounds 不修改模型，自动范围不写入 JSON；PDF snapshot 与 fit 使用同一范围。

editing.js 将约束编辑与绘图事件分开。moveNode 对滑块投影到已有导轨，绝不改写 origin 或 angle；block 指向的杆 / 整体构件同步平移。固连杆另一个端点沿其锁定方向调整长度。moveRail 对机架导轨平移世界基点，对活动导槽平移安装母杆 / 所属整体构件并保持局部基点不变。reconcile 同步杆上铰点、滑块直线位置与固连相对角度；不兼容的移动由调用者整体回滚。

拖动每帧从开始时的几何快照重算，避免累计漂移；一次拖动只占一个撤销步骤。UI 随后重算杆长和实际输入角度。节点 X/Y 编辑使用相同投影操作，母杆端点编辑同步其导槽滑块。导轨的侧向偏置与相对角度仍可在属性中显式编辑，保留用户设计的偏置及十字槽；格式维持 v5。

view 在连杆后、节点前绘制导轨，两侧线均为虚线，独立透明命中区覆盖两侧线而保留杆身中心的选择。选中时蓝色手柄位于基点法向外侧 23 屏幕像素，便于与滑块区分。手柄不进入 PDF 快照。

tests/rail-editing.test.cjs 用独立几何不变量检查约束编辑与安装关系；用正弦机构和转动导杆的解析范围检查自动行程。browser-check-v9.cjs 实测两种导轨及滑块的鼠标拖动、参数输入、整体随动、绑定、撤销和重做，以及手机从虚线直接选中导轨。

### 加入一个新的约束类型

1. 在 `model.js` 中定义、验证并序列化约束。若改变已有字段含义，提升文件版本并提供迁移。
2. 在 `solver.js` 的 `equations` 中加入残差和对未知坐标的导数。解析传播可作为性能优化，数值求解仍以全部残差为准。
3. 在 `view.js` 中绘制新元素，在 `app.js` 中加入创建和属性编辑。修改模型必须经过历史、验证和自动保存。
4. 编写物理或数学上独立的基准测试：验证极限位置、闭环尺寸、坐标变换和无解时行为，不仅仅检查返回 `ok`。

例如，扩展更多构件的角度约束时，需要定义各自的参考点、约束的角度差、相位和周期展开方法。齿轮绘图与角度约束应分别实现；仅画齿轮圆不能产生正确传动。

### 适合重构的方向

随着功能增加，可将约束封装成 `residual / Jacobian` 注册表，并把点模型升级为刚体位姿 `(x,y,theta)` 与局部附件。首版采用点坐标，方便直接绘制多杆机构；移动导轨、凸轮和一般多点构件更适合刚体模型。

当前使用普通脚本和 `globalThis.JiGou` 命名空间，确保双击打开可运行。若迁移至 TypeScript / ES Modules，要同时提供构建输出和离线启动方式，避免只有开发服务器可运行。
