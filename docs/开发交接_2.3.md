# 机构工坊 2.3 开发交接

更新日期：2026-10-15。

2.3 把固定铰点约束放到轨迹合成的预览区，支持先绘制轨迹，再放置两个安装位置并生成机构。GitHub README 与仓库简介同步精简。

## 操作与求解

- 点选顺序是输入铰点 O、另一固定铰点 D。完成后自动锁定；可拖动、输入精确坐标、交换或清除，Esc 可取消未完成的点选。
- 加铰点和拖动铰点不会修改原始目标。修改轨迹宽度时，锁定铰点保持世界坐标。
- 支点约束适用于四杆、齿轮联动五杆。启用后自动模式只比较这两类；原来选择了滑块或行星时切换自动模式，并暂时禁用不适用选项。
- 共用既有求解器的硬安装变换，固定两点同时确定机架距离、方向和安装位置。目标 RMS 仍用于拟合评估，不放宽安装约束。
- 约束栏显示间距、坐标错误及求解后固定铰点的实际偏差。坐标空白不会当成零；重合或超范围时拒绝求解。未完成点选时也不会启动搜索。
- 增加放大、缩小和滚轮缩放，适应预览纳入固定铰点。手机缩放布局更新拖动命中区域。
- 窗口中的撤销同时保存轨迹、约束、来源初值和绘图模式；目标或约束变化使旧候选失效，需要重新计算。

## 保存兼容性

机构结构保持 v9，案例显示设置继续使用 v1 / v2。既有 `synthesis.settings.anchors` 完整保存安装约束。

目标文件继续使用 `jigou-trajectory` v1 / mm，新增可选 `constraints`，保存 `minLength`、`maxLength` 和可选 `anchors`。旧目标不含此字段仍正常读取；旧软件可能忽略新增约束，带约束目标需用 2.3 或更新版求解。读取和导出均验证约束，坏文件不会清空已有设计。

新增案例 `examples/轨迹合成_双固定铰点约束.机构.json`，对应目标在 `examples/轨迹目标`。O=(-30,-25)、D=(70,-25) mm，杆长 2～300 mm，快速搜索最佳四杆 RMS 约 0.680045 mm，候选固定铰点偏差为零。全包共 36 份机构、7 份目标轨迹。

浏览器脚本使用隔离 Edge 和 `?qa=1`，不读取用户自动保存。运行时可设置 `JIGOU_PLAYWRIGHT`、`JIGOU_TEST_PAGE=机构工坊_离线版.html` 和不同 `JIGOU_TEST_PORT`。

## 构建与发布

`node tools/build.cjs` 生成单文件离线版；`tools/build-manual.py` 使用配套 Markdown 生成内嵌图片 HTML 与 PDF。`tools/package-release.py` 只收集运行程序、配套手册、机构/目标案例与教学 DXF，输出到项目的上一级目录；源码完整包可从 GitHub 下载。
