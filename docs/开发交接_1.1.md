# 机构工坊开发交接：1.1

更新日期：2026-10-13。当前对话以 1.0.3 为基线，完成用户提出的凸轮绘制、独立设计窗口、手绘轮廓及蜗杆示例修正。此前约定与历史来源见 [1.0.3 交接](开发交接_1.0.3.md)。

- 项目目录：`G:\机械创新设计\机构工坊`。软件 **1.1**，机构 JSON **v7**，案例设置仍为 **v1**。
- 单文件入口：`机构工坊_离线版.html`；源码入口：`index.html`；发行包：`G:\机械创新设计\机构工坊_v1.1_源码与离线版.zip`。
- 22 个内置示例，26 份可导入文件；旧 v1～v6 文件仍可读，统一保存 v7。

顶部“凸轮设计”和工具栏“凸轮”均打开独立设计窗口，支持直动 / 摆动滚子从动件、基圆与滚子、升程 / 摆角、三类运动规律、推程 / 休止 / 回程、导轨或摆杆安装参数。手绘按绕轴各方向半径采样，支持真实鼠标 / 触摸拖动、平滑、撤销笔画和预览。可生成新机构、共用当前固定输入轴、更新选中凸轮。

`src/cams.js` 负责实际包络、手绘周期样条、接触求交、模型验证、Jacobian 与二阶运动项、安装 / 更新 / 约束拖动及 SVG。`src/camdesigner.js` 负责窗口。solver、motion、model、editing、view、app 均已接入；函数曲线、分享、自动保存和 PDF / CSV 采用原有流程。

新增“直动从动件平面凸轮机构”和“摆动从动件平面凸轮机构”；examples/ 附手绘偏心圆。原 `蜗轮蜗杆_正交轴示意.机构.json` 保留文件名，内容改为阿基米德圆柱蜗杆 ZA 简图，蜗轮与蜗杆处于啮合位置，齿数 / 模数编辑维护中心距。

全部 120 项 Node.js 检查及九组隔离 Edge 浏览器检查通过；8 份 1.1 PDF 渲染查看通过。详细结果见 [验证记录](验证记录.md)，模型与算法见 [开发说明](开发说明.md)，操作说明见 [README](../README.md)。离线构建验证 14 个内嵌脚本；运行软件无第三方依赖。

后续保持已确认的默认操作：闭合回路默认铰接，刚体需要明确合成；固定铰点独立工具；导入 / 统一导出顶栏入口；双 Esc 回到选择；PDF / CSV / JSON 分享保留。应用不计算受力或动力学。凸轮持续接触，手绘限定绕轴单值半径；手绘加速度使用数值导数，蜗杆为教学简图。

无需修改浏览器正常自动保存键来测试。使用 `?qa=1` 与隔离浏览器，修改源码后执行 `node tools/build.cjs` 生成单文件离线版。
