## 已确认的交互与计算要求

1. **闭合回路默认保持铰接。**用户在澄清中明确选择“只闭合连杆回路，顶点仍是铰接”。整体刚性构件必须显式选择，不能把普通闭环自动合成刚体。
2. Jansen 的两个三角部分作为整体构件计数，足端 H 不算转动副；该示例为 `n=7、Pₗ=10、Pₕ=0、F=1`。
3. 固定铰点位于绘图指令中、紧邻添加铰点；属性中不再设置重复的固定复选框。
4. 顶部使用“导入机构”；导出集中在其旁边。已删除右侧底部导出区和用户 SVG 下载入口；内部 SVG 仍用于画布与 PDF。
5. 示例集中在一个“机构示例”按钮中；杆上点与伸出杆使用各自独立图标。
6. 杆上铰点可继续连接独立杆。杆上观测点和伸出端属于母杆附着结构，不额外增加自由度，目前不能充当新独立杆的约束铰点。
7. 两类导轨均画虚线并覆盖完整行程。拖动滑块沿原导轨投影，不能误改导轨基点、母杆引用或安装偏置；拖动活动导槽时安装母杆同步移动。
8. 播放倍速仅控制动画节奏。速度、加速度、时间轴和导出数据始终按真实输入转速或摆动频率计算；倍速保存为浏览器个人偏好，不写入机构 JSON。
9. X–Y 按运动采样顺序连接，横纵轴每 mm 的显示比例一致；每个节点使用自身 X 坐标。分速度保留正负号，同一节点同色，Vx 实线、Vy 虚线。
10. 多周齿轮传动保留累计输入角和完整回位周期，不折叠为一圈。不可达或奇异采样应提示或断开，不把缺失运动学数据伪造为零。
11. 界面及导出使用中文。已有浏览器检查包含 390 / 320 px 窄屏，新增交互应继续兼容。

## 代码入口与约束

所有脚本通过 `globalThis.JiGou` 组合，按 `index.html` 中的顺序加载，当前共 12 个脚本。数学模块支持 Node.js `require`；独立调用时先初始化依赖，例如先加载 geometry 和 model，再加载 cases。`cases.read` 接受解析后的 JSON 对象。

| 文件 | 职责 |
| --- | --- |
| `index.html`、`styles.css` | 中文控件、对话框、图标、布局与响应式样式 |
| `src/geometry.js` | 几何求交、线性方程、矩阵秩、网格与吸附辅助 |
| `src/model.js` | 模型验证与迁移、内置示例、构件/运动副计数、杆上铰点、附着点 |
| `src/gears.js` | 齿轮模型、啮合方程、传动比、参数编辑、轮系周期及齿轮渲染 |
| `src/drive.js` | 旋转/摆动规律、累计相位、周期采样计划 |
| `src/cases.js` | 案例显示设置、输入相位与模型的验证及往返 |
| `src/solver.js` | 几何传播和数值约束求解、Jacobian、自由度、速度方程 |
| `src/motion.js` | 速度、加速度、角速度及附着点运动学 |
| `src/editing.js` | 滑块投影、导轨平移、固连构件随动与编辑协调 |
| `src/view.js` | SVG 画布、视口、轨迹、快照和示例缩略图 |
| `src/curves.js` | 周期曲线采样、物理量、坐标轴、图表 SVG 与曲线 CSV |
| `src/export.js` | 图像 PDF 编码与机构/图表排版 |
| `src/app.js` | 绘图事件、属性编辑、历史、缓存、仿真播放、存储及导入导出流程 |
| `tools/build.cjs` | 从分文件源码生成完整单文件离线 HTML，检查脚本语法及外部依赖 |
| `tools/server.cjs` | 仅监听 127.0.0.1 的开发服务器，默认 4173 |
| `tests/`、`tools/browser-check*.cjs` | 数学/格式测试与浏览器交互验证 |

模型保存初始坐标、结构和约束，仿真帧保存另一份坐标映射，求解器不修改传入模型。单位为 mm、度，X 向右、Y 向上、角度逆时针为正；SVG 显示层翻转 Y。几何解析传播不足时采用带阻尼的数值约束求解，最终最大约束残差接受阈值为 `1e-5 mm`。运动学按约束导数计算。

正常自动保存键为 `jigou-workshop-v1`，案例列表键为 `jigou-workshop-cases-v1`，倍速键为 `jigou-workshop-v1-playback-rate`。`?qa=1` 使用隔离键；浏览器检查应继续使用隔离会话与测试模式。
