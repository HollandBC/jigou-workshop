# Linkage 功能对比与机构工坊 2.2

对比依据为 David Rector 的 [Linkage 3.16 官方用户手册](https://www.rectorsquid.com/Linkage.pdf)（2024-11-26）和 [在线帮助目录](https://www.rectorsquid.com/Linkage/index.html)，不是 Wolfram 的 LinkageDesigner。本次查阅文档，没有安装或运行 Linkage；在线帮助自述仍在编写，不能将文档未列出的功能断言为软件没有。

| 设计环节 | Linkage 文档描述 | 机构工坊现状 |
| --- | --- | --- |
| 连杆、铰点与滑动连接 | 绘图、驱动与仿真 | 已支持独立铰点、闭合回路、刚性构件、固定 / 活动导轨 |
| 齿轮与凸轮 | 齿轮 / 链传动、样条凸轮 | 已支持齿轮和轮系，参数化 / 手绘直动及摆动凸轮；链和通用样条导轨待扩展 |
| 从图纸复建 | 背景图片随文件保存 | **2.2 新增底图导入、两点标定、位置 / 旋转 / 透明度** |
| 尺寸与量测 | 自动尺寸、测量元素与机架标注 | 原有杆长；**2.2 新增关联观测点的距离与三点小角测量** |
| CAD 交接 | DXF 导出；手册注明该版本导出尚有限制 | **2.2 新增毫米坐标 R2000 DXF**，分层静态几何与轨迹 |
| 路径和数据 | 路径数据、图片与打印 | 已有 PDF、全周期运动学 CSV、X–Y 与分量曲线对比 |
| 目标轨迹逆向合成 | 本次查阅手册未见对应说明 | 当前有四杆、曲柄滑块、齿轮联动五杆、行星齿轮四类候选 |
| 零件视图与演示视频 | 零件展开视图、视频导出 | 当前未加入；可以作为后续专门功能 |

优先选择这三项，是因为它们直接补全“图纸参照 → 按比例搭建 → 观察尺寸 → 交给 CAD”的流程，也适合现有离线单文件架构。实现独立编写，沿用原求解器；辅助绘图不参与物理约束，不改变自由度。

底图采用嵌入图像，支持隐藏与撤销；标定只调整图像比例，不缩放机构。测量绑定节点、杆上点或伸出端，随真实位形更新。DXF 写入当前世界坐标、毫米单位、杆件、导轨、凸轮轮廓、齿轮节圆和开启的轨迹；不复制图像或制造外形。格式依据 [Autodesk LWPOLYLINE 说明](https://help.autodesk.com/cloudhelp/2017/ENU/AutoCAD-DXF/files/GUID-748FC305-F3F2-4F74-825A-61F04D757A50.htm)及 [DXF 组码参考](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-DXF/files/GUID-3F0380A5-1C15-464D-BC66-2C5F094BCFB9.htm)，另用 ezdxf 独立读取审计。

曲线导轨 / 非径向凸轮、链传动、多输入及直线执行器需要扩展约束求解；零件展开和视频需要另设设计与演示流程。本版不为填齐功能表而以绘图动画替代约束运动。详细步骤见 [2.2 使用说明书第 14 章](机构工坊_使用说明书_2.2.html#chapter-14)。
